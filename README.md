# Fahad.help V1

هذه نسخة أولى جاهزة للعمل كموقع ثابت.

## التشغيل على الكمبيوتر
افتح ملف `index.html` مباشرة في المتصفح.

## النشر المجاني
يمكن رفع المجلد كما هو إلى:
- Cloudflare Pages
- Netlify
- GitHub Pages
- Vercel

## ربط الدومين
بعد النشر، أضف `fahad.help` من إعدادات المنصة، ثم انسخ سجلات DNS إلى Porkbun.

## الملفات
- `index.html`: الصفحة
- `styles.css`: التصميم
- `script.js`: اللغة والأدوات التفاعلية
- `assets/fahad.jpg`: صورة فهد الأصلية
- `assets/logo.svg`: نسخة متجهية من اتجاه الشعار المعتمد

ملاحظة: الأسعار والأنظمة السعودية لم يتم ربطها بأنظمة رسمية؛ الأدوات الحالية حسابات عامة وتجريبية.
